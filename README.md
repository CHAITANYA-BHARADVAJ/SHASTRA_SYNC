**Teammate 3 Module** — An elderly-first, voice-empowered tablet application designed for seniors (Kamala Devi). It provides ambient monitoring, a living conversational care companion, bidirectional synchronization with the Family Dashboard (Teammate 4), and autonomous event dispatching to the AI Core (Teammate 2).

---

## 🌟 Key Features

### 1. Living AI Companion Sanctuary (Top Hero Card)
- **Ambient Voice Interaction:** Tap the central glowing microphone to talk directly to your care companion.
- **Real-Time Live Speech Streaming:** As you speak, recognized words stream onto the card in bold real-time text before finalizing.
- **5-Second Auto-Closing Window:** Strict 5-second recording duration with an animated countdown pill (`🎙️ Listening (5s)...`).
- **AI Core Direct Voice Playback:** Speaks all responses, inquiries, and check-ins generated by the **AI Core (Teammate 2 AgentDecision)** aloud with crystal clarity.
- **Voice Replay:** Includes a `🔊 Replay Voice` button allowing seniors to re-listen to any AI response.

### 2. Bidirectional Family Dashboard Sync (Teammate 4 Link)
- **Verbatim Message Delivery:** Displays incoming text messages (both quick predefined and custom typed notes) from Priya (Daughter) character-for-character with zero AI rephrasing or unwanted alteration.
- **7-Second Auto-Reset:** When a family message is received, it displays verbatim for 7 seconds and then automatically returns to the comforting default state.
- **Dedicated 5-Second Voice Reply:** Tap `🎙️ Voice Reply` to record a 5-second voice note that is instantly dispatched to Priya's Family Dashboard via WebSocket (`family_reply`) and REST API (`voice_input`).
- **Direct Family Calling:** Tap `📞 Call Priya` to trigger a high-priority call banner on Priya's Family Dashboard.

### 3. Full-Screen Incoming & Active Call System
- **Full-Screen Call Popups:** When a call invite arrives from the Family Dashboard (Schema D `CallInvite` or voice call event), the app triggers an animated ringing overlay with caller avatar, chime, and large green **📞 Answer & Talk** and red **✕ Decline** buttons.
- **Zero Call Looping:** Incorporates a strict `handledCallsRef` deduplication filter and status-interception pipeline that completely prevents infinite call loops.
- **Active Call In-Progress Screen:** Answering transitions immediately to a dedicated in-call overlay with live duration timer (`● LIVE CALL CONNECTED 00:15`) and a prominent **🔴 End Call** button.

### 4. Multi-Language Natural Speech Synthesizer
- **Authentic Neural Voices:** Explicitly targets Microsoft Natural Online and Google regional voices for **Kannada (`kn-IN`)**, **Hindi (`hi-IN`)**, **Tamil (`ta-IN`)**, **Telugu (`te-IN`)**, and **English (`en-IN` / `en-US`)**.
- **Robotic Voice Exclusion:** Automatically suppresses crackly or weird legacy voices (such as `Microsoft Ravi` or `Microsoft Neera`).
- **Language-Tailored Cadence:** Speaks Indic languages at a gentle `0.90x` rate for crisp syllable articulation and English at `1.0x` conversational speed.
- **Automatic Script Detection:** Inspects text characters dynamically (e.g. Kannada Unicode `\u0C80-\u0CFF`) to guarantee proper pronunciation.

### 5. Fall Detection & Emergency SOS
- **Emergency SOS Button:** One-tap high-urgency SOS alert broadcasted to the Hub and Family Dashboard.
- **Vocal Fall Cancellation:** Allows the elder to speak *"I am fine"* or *"I am okay"* to dismiss false-positive fall check-ins safely.

## 📡 System Integration & Schemas

The Elder App communicates with the shared FastAPI Hub and WebSocket stream using standardized contracts:

| Schema | Direction | Protocol | Purpose |
|---|---|---|---|
| **Schema A (`SensorEvent`)** | Elder $\rightarrow$ Hub | HTTP `POST /api/events` | Dispatches voice transcripts, SOS triggers, fall responses, and wellness check-ins. |
| **Schema B (`AgentDecision`)** | AI Core $\rightarrow$ Elder | WebSocket `/ws/alerts` | Receives autonomous agent decisions, voice inquiries, and synthesized speech responses. |
| **Schema C (`FamilyAlert`)** | Hub $\rightarrow$ Elder / Family | WebSocket `/ws/alerts` | Broadcasts emergency alerts, fall events, and family notifications. |
| **Schema D (`CallInvite`)** | Family $\rightarrow$ Elder | WebSocket `/ws/alerts` | Triggers the ringing incoming call screen on the elder tablet. |
| **Schema E (`CallResponse`)** | Elder $\rightarrow$ Family | WebSocket `/ws/alerts` | Reports call acceptance or decline back to the family dashboard. |

## 🚀 Getting Started Locally

### Prerequisites
- Node.js 18+
- Google Chrome or Microsoft Edge (required for Web Speech API microphone access)

### Installation
```bash
# Clone the repository
git clone https://github.com/SumedhSA3021/Teammate3_ElderlyAppV3.git

# Navigate into project directory
cd Teammate3_ElderlyAppV3

# Install dependencies
npm install

# Launch local development server
npm run dev
```

Open [https://localhost:5173/](https://localhost:5173/) in your browser.

## ☁️ Deployment on Vercel

The project includes a ready-to-deploy [`vercel.json`](./vercel.json) configured for Vite Single Page Application routing.

### Deploying via Vercel Web Dashboard:
1. Go to [vercel.com](https://vercel.com/) and click **Add New Project**.
2. Import **`SumedhSA3021/Teammate3_ElderlyAppV3`**.
3. Under **Build and Output Settings**:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Under **Environment Variables**, add:
   - `VITE_API_URL` = `https://3.110.50.100.nip.io`
   - `VITE_WS_URL` = `wss://3.110.50.100.nip.io/ws/alerts`
   - `VITE_ELDER_ID` = `elder_kamala_001`
5. Click **Deploy**. Vercel will build and assign an HTTPS URL automatically.

### 🔒 HTTPS Requirement for Microphone Access:
The Web Speech API (`SpeechRecognition` & `getUserMedia`) requires a **secure context (`https://`)** to function in browsers. Vercel automatically provisions SSL certificates on all deployment domains.
